# Crystal Defects Lab · تاقیگەی کەموکوڕییەکانی کریستاڵ

**Solid State Physics, Chapter 3: Crystal Defects & Dislocations**
Department of Physics, University of Raparin

**Open the lab:** https://inqader-bit.github.io/crystal-defects-lab/

An interactive, bilingual (English / Kurdish Sorani) simulation built from the Chapter 3 lecture notes of Ibrahim Nazem Qader. It uses Kittel, *Introduction to Solid State Physics* (Ch. 20 Point Defects, Ch. 21 Dislocations) and Ashcroft & Mermin, *Solid State Physics* (Ch. 30 Defects in Crystals) as references.

## What is inside

- **Seven hands-on labs.**
  - Point defects and thermodynamics.
  - Edge dislocation: glide, Burgers circuit, annihilation and climb.
  - Screw and mixed dislocations, with spiral growth.
  - Ideal vs real strength, Frank–Read source and work hardening.
  - Stress fields and dislocation interactions.
  - Planar defects: tilt boundary, stacking faults, twin and grains.
  - Volume defects: precipitates, Orowan loops, pores and cracks.
- **Exam bank.** 153 questions in 14 formats. It has a practice mode and a timed exam mode, and the numerical questions generate new numbers each time.
- **Applications & ventures.** 14 application cards, each linked to an edupreneurship venture idea and a class mini-project. They come with a venture builder and a break-even calculator.
- **Formula sheet.** Every equation used, with its source.
- **Display options.** Day and night modes, with layouts for phones (9:16) and computers (16:9).
- **Languages.** English and Kurdish (Sorani). The Kurdish mode reads right to left; use the button in the top bar to switch.

The whole lab is a single self-contained `index.html` file. It works offline once downloaded; the fonts load from the web when a connection is available.
